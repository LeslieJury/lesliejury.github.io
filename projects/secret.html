Hexcode Game

A hands-on RGB guessing game where players adjust red, green, and blue values with potentiometers to match a hidden hexadecimal color.

Project demonstration

How it works

The game turns color theory into a physical challenge. Potentiometers control the RGB channels, while the hardware translates each adjustment into a hexadecimal color value. Players keep tuning the controls until their color matches the target.

Physical controls

Potentiometers give the player direct control over each color channel.

Color logic

RGB values are combined and compared as hexadecimal color codes.

Interactive feedback

The electronics make the result immediate and easy to understand while playing.

Hardware setup
