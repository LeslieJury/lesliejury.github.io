Cyberdeck

A portable Raspberry Pi computer built around a compact, hands-on setup. I designed the layout, experimented with different enclosures, and used the project to learn more about Linux and hardware integration.

From shoebox to lunchbox

The first prototype lived in a shoebox. I later moved the setup into a small tin lunchbox, which made the build more compact and much easier to carry. The project is still evolving as I test better mounting and cable-management ideas.

System layout

The diagram shows how the Raspberry Pi, display, input devices, and supporting peripherals fit together. Planning the physical arrangement has been just as important as getting the software running.
